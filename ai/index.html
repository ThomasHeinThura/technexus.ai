Context · constraints

A first step, not a datacenter

Four voices shape every design.

Regulator · CISO
“Data stays in-country.”

Every inference auditable. Rules out hosted APIs.

Infrastructure
“GPUs ship in quarters.”

The design must survive a hardware swap.

Platform team
“We know Docker, not GPUs.”

Automate the driver and CUDA lifecycle.

CEO · CFO
“When does it pay back?”

Unit economics, not benchmarks.

On-prem is not automatically right. Rent first. Own only when residency, utilisation or cost per token demand it.

Compute · four paths

Four paths, one platform

The serving layer never changes, so hardware stays reversible.

1 · Rent

GPU-as-a-Service

Hourly rental · container in, endpoint out

  • Live the same day
  • Pilots and benchmarks
  • Data leaves the country
CommitmentHourly · cancel anytime
2 · Desktop class

NVIDIA DGX Spark

GB10 · 128 GB unified · 273 GB/s · ~1 PFLOP FP4

  • Off the shelf, on-prem
  • Up to ~200B params; two linked ~405B
  • 273 GB/s limits decode speed
Entry pointDesktop unit · ~US$4.7k list
3 · Lowest capex

GPU retrofit

One 48–96 GB card in a validated host

  • Cheapest on-prem inference
  • One or two quantized models
  • No HA on one chassis
Entry pointCard only · validate host
4 · Production

Dedicated GPU server

2× 96 GB GPUs · 512 GB ECC · 25 GbE

  • 3–5 models concurrently
  • Second node = HA pair
  • Credible production SLA
CommitmentCapex + facility ready
Compute · journey

Prove it rented, then own it

Rent → prove → own. Moving between paths is a migration, not a rebuild.
